# 무협 프로젝트 설계

선협 프로젝트(`선협` 브랜치)를 멈추고, 같은 엔진·설정에서 무협만으로 다시 짠다. 언제든 선협으로 돌아갈 수 있다.

## 정한 것

- **선협 설정을 모두 뺀다**: 용(그분), 하늘의 틈, 영계, 재앙과 그것들, 수도자·영근·신식, 천기누설, 노인과 소년, 회색 도포와 진법.
- **가져가는 것**: 지금까지 만든 무협 설정(인연, 세력, 사건, 경지, 무공, 반복되는 생·업·체질 같은 장치)은 바탕으로 쓴다. 이야기 구조는 처음부터 다시 짠다.
- **무협 집단을 크게 늘린다**: 문파·세가·방회·관부·장사꾼 집단 등.
- **경지 상승을 훨씬 더디게**: 평생 수련해도 삼류·이류 언저리에서 수명이 다할 수 있다.

## 정할 것

- 주인공이 다른 세상에서 온 사람인지(선협 쪽으로 분류했던 설정)
- 반복되는 생을 유지할지
- 나이와 수명을 어떻게 셀지(경지가 더뎌지면 '시간'이 핵심이 된다)
- 최종 목표와 결말
