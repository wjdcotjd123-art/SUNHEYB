# 2부(이어진 길) 줄기 지도

장면을 쓰기 전에 이 지도를 먼저 고친다. 줄기마다 **경지를 넘어 같은 표시를 공유**해서, 뒤 장면이 앞 장면을 항상 알게 한다.

표기: `[일류]` `[절정]` 장면이 나오는 경지 / `→` 다음 장면 / `{표시}` 공유 표시 / ★ 새로 만들 장면

---

## 0. 큰 흐름

프롤로그(기억 갈래) → [일류] 표류: 단서 줄기들 → 단서 3개 → 확신 → 다짐 → 철검 장로의 밤(절정 돌파, 이미 늦음)
→ [절정] 정사대전 + 경계 줄기들 → 누구의 소행인가 → 검은 깃발 → (3단계: 마교 토벌) → (4단계: 수도자)

### 0-1. 이야기 뼈대 (플레이어가 외우지 않고 따라오게)

| 단계 | 장면 | 주인공의 생각 |
|---|---|---|
| 목적 | 확신(R01) → 다짐(R06) | "이번에는 막겠다. 더는, 잃지 않겠다." |
| 첫 행동 | 철검 장로의 밤(R07) | 장로를 지키러 달려가다 절정. 그래도 늦음 |
| 중재 | 다시 붙은 불(S01) → 인물 싸움터 | 이미 시작됐다. 말린다. 관망 선택지 없음. 장면 첫 줄에 '말리러 왔다' |
| 의심 | 싸움터 끝마다 한 줄 | "정파도 사파도 한 일이 아니다." |
| 결론 | 누구의 소행인가(S06) | 의심을 두세 줄로 다시 짚고 "배후가 있다" → 활동 중인 마교 |
| 결심 | 검은 깃발(S07) | 증거를 잡아 오해를 풀려고 혼자 마교를 치기로 |
| 토벌 | [초절정 전반] 흔적 추적 → [초절정 후반] 총단 | 천마도 나를 원흉으로 오해해 맞붙음 → 둘 다 틀림 |
| 천마 | 벤다(기본) / 정보 때문에 살려 둠 → 원흉 결전에서 진법을 탐내 벤다 | 천마는 악인 그대로. 베는 것은 살업 아님 |
| 원흉 | 수도자(진법) | — |

- 줄기마다 핵심 장치는 하나. 화살·가짜 전갈 같은 잔 장치 없음.

## 1. 단서 줄기 (일류, 줄기 끝에서 단서)

| 줄기 | 장면 | 공유 표시 | 절정으로 이어짐 |
|---|---|---|---|
| 악몽 | 악몽 → ★두 번째 꿈(잿더미 속 마을과 우물) → 단서 | {길_우물} | 없음 |
| 청하촌 | 청하촌의 우물 → ★청하무관 마당(촌장·아이) → 단서 | {청하촌_감} {길_무림맹} | 검은 깃발: 피난민 속 청하촌 사람 |
| 무림맹 | 무림맹 본산 → ★다시 선 산문(산문지기·집법 노인) → 단서 | {집법_만남} | 맹의 추궁: 집법 노인이 나를 알아봄 |
| 흑풍채 | 산적의 길목 → 앙갚음 / 돌아온 전낭 / 괴물이 나타났다 → ★산채 깃발 앞 → 단서 | {흑풍_은혜·원한·무심} | 두 곳의 불: 사파 쪽에 흑풍채가 섞여 있음(대한 대로 반응) |
| 유진 | 고갯길의 매복 → ★다시 만난 표국 → 단서* | {유진_은혜·무심} | 전생 연계(유진) |
| 연화린 | 마교의 추격 → ★붉은 끈의 빚 → 단서* | {화린_도움·존중·검} | 화산 경계에 함께 나옴 |
| 철우강 | 장터의 거한 → ★다시 붙자 → 단서* | {우강_호감·속임·무심} | 두 곳의 불(선봉) → 패천문 경계 |
| 소월 | 비 오는 밤(기억) → ★객잔의 검은 옷(스침) → 단서* | {소월_스침2} | 사도련 살수로 옴 |
| 화산 | 매화의 기수식 → ★다시 찾아온 제자 → 단서* | {화산_대함: 얼버무림·꿈·달아남·겨룸} | 화산 경계: 문주가 직접 옴 |
| 남궁 | 남궁의 검로 → ★다시 찾아온 검수 → 단서* | {남궁_대함} | 남궁 경계: 가주가 직접 옴 |

\* 인물 단서는 지난 생에 그 인물과 겪은 일이 있을 때만 단서가 된다. 없으면 만남만 남는다.

- 단서 3개면 확신. 누구나 얻는 줄기 넷(악몽·청하촌·무림맹·흑풍채) 중 셋만으로도 갈 수 있다.
- 인물 줄기의 일류 단계 = 첫 만남과 작은 도움. 큰 갈림길은 절정(전생 연계)에서.

## 2. 소문 줄기 (일류 → 절정)

드러냄 표시 쌓임 → 같은 일류 / 노 씨의 소문 / 팔려 간 이름 / 이름 없는 고수(키움·덮음)
→ [절정] 소문이 크면 경계 장면이 더 일찍, 덮었으면 늦게·적게. 하오문 경계는 '이름 없는 고수'의 다음 단계.

공유: {소문_큼} {소문_덮음} {별호_맨손}

## 3. 마교 줄기 (일류 → 절정 → 3단계)

마교의 추격(살려 보냄 / 붙잡아 캠) → 검은 옷의 손님 {마교_표적} → [절정] 검은 깃발(표적이었으면 마교가 먼저 나를 찾음) → 3단계 마교 저지

## 4. 배후 줄기 (흔적만, 드러내지 않음)

[일류] 이름 없는 고수: 회색 도포의 손님 {회색_도포}
[절정] 창틀의 흠집 {단서_장로} / 밀고장 {단서_밀고} / 나그네 {단서_나그네} / 빈 시신 {단서_빈_시신} → 누구의 소행인가

## 5. 정사대전 줄기 (절정) — 핵심 인물 중심

다시 붙은 불 → 인물 싸움터(아래) + 기존 장면(곁가지) → 누구의 소행인가 → 검은 깃발

### 5-1. 인물 싸움터

| 장면 | 중심 인물 | 소속 | 상황 | 기존 장면과 관계 |
|---|---|---|---|---|
| ★사제의 원수 | 연화린 | 화산·정파 | 사도련에 사제를 잃고, 상관없는 사파 사내들을 대신 베려 한다 | '풀어 준 포로'와 짝(같은 날 반대편). 하원은 남김 |
| 강변의 토벌(수정) | 남궁현 | 남궁·정파 | 토벌대에 합류했지만 양민이 죽자 흔들린다. 엄 대주 곁 | 기존 장면에 남궁현을 넣음 |
| 두 곳의 불(수정) | 철우강 | 패천문·사파 | 선봉을 이끈다. 1부처럼 무너질 수 있다 | 선봉 사내 = 철우강 |
| 말라 죽은 무인(수정) | 소월 | 흑사문·사파 | 피해자가 흑사문 살수. 소월이 조사하러 와서 마주친다 | 기존 장면에 소월을 넣음 |
| ★양쪽의 짐 | 유진 | 청하표국·중립 | 양쪽에 물자를 대다 표국이 몰린다 | 새 장면 |

- 각 인물 싸움터 뒤에 ★두 번째 만남(반응 장면)을 둔다 → 그 인물의 경계 장면·전생 연계로 이어짐.
- 곁가지(엄 대주, 하원, 곰배)는 개연성을 해치지 않으면 그대로 둔다.

### 5-2. 선택지 순서

**중립 → 그 인물의 소속 쪽 → 반대 진영 → 외면.** 비살생이 기본.

### 5-3. 대함 기록 (인물마다)

`{인물}_중립` / `{인물}_도움`(인물 소속 쪽을 도움) / `{인물}_적대`(반대 진영을 도움) / `{인물}_외면`
+ 결과 표시 `{인물}_결과_살림`(중립으로 사람이 살았음을 그 인물이 봄)

### 5-4. 반응 (첫 반응 → 결과를 본 뒤)

| 인물 | 중립 | 도움 | 적대 | 외면 | 결과를 본 뒤(중립) |
|---|---|---|---|---|---|
| 연화린 | "…저놈들은 사파라고!" 화를 냄 | 퉁명스럽게 고마워함("…빚진 거 아니야.") | 다음 만남에 먼저 검을 뽑음 | 경멸 | "…이번만이야." |
| 남궁현 | "그 길은 외롭소." 존중하되 거리 | 정중한 감사, 호적수로 인정 | 정중한 결투 신청 | 실망을 숨김 | "당신 같은 사람이 하나쯤은 있어야겠지." |
| 철우강 | "싸우지도 않을 거면 왜 왔냐!" | "크하하! 역시 너는!" | "좋다, 그럼 너랑 붙으면 되겠군!" | 웃지 않음 | 동료가 살면 "…빚이다." |
| 소월 | "…베는 쪽이 훨씬 쉬웠을 텐데." | "…알았어." (빚으로 기억) | "…알았어." 거리를 둠. 련의 청부를 피하지 않음 | 아무 말 없음 | 살수로 와서 망설임이 남음 |
| 유진 | 반가워함(같은 중립) | 고마워하며 걱정 | "한쪽에 서면 다른 쪽 칼이 다 당신을 향하오." | 서운함 | 표국 위기 때 먼저 손을 내밈 |

### 5-5. 일류 만남 · 전생 기억과의 연결

- 일류에서 만났으면: 대함 기록(은혜·원한·무심)을 이어서 본다. "너, 그때 그…"
- 처음 보면: 싸움터가 첫 만남.
- 지난 생에 그 인물이 어떻게 됐는지 기억나면(past_known_any): 그 앞날을 막는 선택지가 열린다(전생 연계). 왜 아는지는 말할 수 없다(털어놓으면 천기누설).

공유: {막음_무림맹} {막음_사도련} {엄대주_원한} {곰배_원한 → 련_표적} {하원_구함·죽음·흔들림} + 인물 대함 기록

## 6. 경계 줄기 (절정) — 모두 앞 줄기의 다음 단계

| 집단 | 앞 단계(있으면) | 없으면 시작 | 비고 |
|---|---|---|---|
| 화산 | 화산 줄기(일류) | 전쟁터에서 내 초식을 본 자가 알림 | 연화린 동행 시, 마교의 추격에서 만났는지 반영 |
| 남궁 | 남궁 줄기(일류) | 같음 | 남궁현 동행 |
| 무림맹 | 맹의 추궁 {맹_주시} | 경계 장면 따로 두지 않음(맹의 추궁이 그 역할) | 집법 노인 |
| 사도련 | 외눈의 앙갚음 {련_표적} 또는 {막음_사도련} | — | 소월이 살수로 옴. 소월 줄기(일류)에서 스쳤는지 반영 |
| 패천문 | 두 곳의 불 {패천문_선봉_꺾음} 또는 철우강 줄기 | — | 문주가 시험하러 옴. 철우강: "…다음엔, 안 진다." |
| 귀영각 | 걷는 시체 {드러냄_시체} {귀영각_사당} | — | 내공을 탐냄. 배후 의심은 하지 않음 |
| 하오문 | 이름 없는 고수 | 소문이 크면 | 내 정보 값 |
| 마교 | 검은 옷의 손님 {마교_표적} | — | 검은 깃발과 이어짐 |

## 7. 겹치는 인물 정리

- **연화린**: 마교의 추격(일류) → 붉은 끈의 빚(일류) → 화산 경계(절정). 뒤 장면은 앞의 대함 표시를 본다.
- **철우강**: 장터의 거한 → 다시 붙자 → 패천문 경계. 두 곳의 불의 선봉은 철우강이다.
- **소월**: 비 오는 밤(기억) → 객잔의 검은 옷 → 사도련 살수.
- **하원·엄 대주·곰배**: 절정에서만 나오는 곁가지.
- **남궁현**: 남궁 줄기(일류) → 강변의 토벌(절정) → 남궁 경계.
- **유진**: 고갯길의 매복(일류) → 다시 만난 표국 → 양쪽의 짐(절정).
- **노 씨**: 일류 내내. 절정에서는 소문 전달자로만 짧게.

## 8. 공통 규칙

- 다시 나오는 인물은 대함 기록(은혜·원한·무심)에 따라 반응이 갈린다.
- 정사대전 선택지 순서: 중립 → 그 장면 인물의 소속 쪽 → 반대 진영 → 외면(인물이 없으면 중립 → 정파 → 사파 → 외면). 비살생이 기본.
- 가독성 규칙(README).
- 전생을 털어놓으면 천기누설.


## 9. 살생과 갈림 (정한 것)

- 싸움터 살생('정파·사파 양쪽에 강경하게 나서')을 **세 번 이상** 하면 표시가 쌓인 것으로 본다(살업_토벌·포로·선봉·시신·짐 중 3).
- 이 조건이면 2부 끝 **수도문파를 정할 때 새 선택지**(사도 수도문파)가 열린다.
- 이미 반영: 총단의 문에서 마교도가 먼저 겁을 먹음.
- 공포로 정사대전이 멎는 갈림은 **만들지 않는다**. 살생은 이야기의 큰 줄기를 바꾸지 않고, 인물 반응과 수도문파 선택지만 바꾼다.
