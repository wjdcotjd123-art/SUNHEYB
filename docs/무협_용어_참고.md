# 무협 용어·클리셰 참고 (무협 프로젝트 전용)

> 이 문서는 `무협` 브랜치에만 둔다. 선협 프로젝트에는 적용하지 않는다.

받은 참고 글(무협 소설의 용어와 클리셰를 가볍게 정리한 글)에서 표제어만 추렸다. 원문은 저장소에 두지 않는다.

## 쓰는 원칙
- **용어를 상황에 맞게 자주 쓴다.** 참고 글만큼 무협 용어가 자연스럽게, 자주 나와야 한다.
- **클리셰는 살리되, 비틀어도 된다.** 참고 글의 내용이 다 맞는 것은 아니다.
- **말투는 따라 하지 않는다.** 참고 글의 농담조·비꼬는 투는 쓰지 않는다. 우리 글의 문체 규칙(README)을 따른다.
- 새 용어를 쓰면 용어집(`lang/ko/glossary.json`)에 풀이를 더한다.
